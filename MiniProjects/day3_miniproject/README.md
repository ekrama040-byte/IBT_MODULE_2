# Awash Specialty Coffee Lounge — Profile Card

A fully responsive, highly semantic business profile card dedicated to an upscale fictional coffee roasting company situated within the Bole sub-city of Addis Ababa, Ethiopia.

## How to Deploy and Inspect Locally

1. Confirm that `index.html` and `styles.css` are saved in the same absolute directory level (`day13/`).
2. Double-click or drag `index.html` directly into any modern desktop internet browser environment (Chrome, Firefox, Safari).
3. Access developer tools using **F12** or by right-clicking on the profile element container canvas and selecting **Inspect**.
4. Test keyboard focus mechanics natively by hitting the `Tab` sequence key to seamlessly drop onto the operational Call-to-Action control framework.

## Advanced CSS Techniques Demonstrated

*   **Global Layout Normalization:** Implements structural `box-sizing: border-box` transformations systemwide via wildcard selectors ensuring clear architectural component bounds without width contamination.
*   **Centralized Variable Architecture:** Declares centralized architectural color design scopes and strict spacing tokens under global `:root` hooks maps referenced explicitly across component nodes via functional `var()` hooks.
*   **Mathematical Functional Color Space Tuning:** Implements advanced functional color mappings via HSL channels where standard component hover changes maintain accurate color rendering balances by cleanly targeting the third lightness index profile vector exclusively.
*   **Decoupled Decorative Pseudo Elements:** Injects structural gold border layout strips natively without bloating structural HTML trees via localized absolute mapping variables applied over structural `.card-hero::before` canvas rules.
*   **Calibrated Typographic Scales:** Establishes distinct rendering sizing structures utilizing font-weight offsets combined with balanced font heights optimized visually for user legibility.
